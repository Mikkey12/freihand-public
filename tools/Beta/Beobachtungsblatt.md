# Beobachtungsblatt Freihand-Beta

Je Problem eine Zeile. **Keinen Diktattext** hineinschreiben, nur was passiert ist. Wer gleich nach dem Problem
„Problem merken“ drückt (Strg+Alt+B oder Menü), schreibt hier die Nummer aus der Pille dazu; die Auswertung
(`Freihand-Auswertung.ps1`) zeigt dieselbe Nummer mit Uhrzeit.

| Datum | Zeit | Marke Nr. | Programm | Was ist passiert? (ohne Diktatinhalt) | Wie schlimm? (1 lästig – 3 Text verloren) |
| --- | --- | --- | --- | --- | --- |
| | | | | | |
| | | | | | |
| | | | | | |

Beispiele, wie eine Zeile aussehen kann:

- „Outlook, Antwort: zweiter Satz kam nicht an, stand im Diktatfenster“
- „Word: Pille blieb rot, obwohl ich gestoppt hatte“
- „Korrigieren: Vorschlag hat eine Zahl geändert, Warnung kam“
